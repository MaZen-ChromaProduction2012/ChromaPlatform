# 🎬 ChromaProduction — منصة المونتاج الذكي المتكاملة

منصة ويب احترافية مصممة خصيصاً لإدارة عمليات المونتاج، تربط محرري الفيديو بصناع المحتوى والعملاء، وتدير دورة العمل كاملة من استلام الماتريال حتى التسليم النهائي، مع تكامل ذكي لبوت تيليجرام ومحرك C++ لمعالجة الملفات.

---

## 🏗️ هيكلية المشروع (Project Architecture)

```
ChromaProduction/
├── frontend/                  # واجهات المستخدم (Tailwind CSS + Vanilla JS)
│   ├── index.html             # الصفحة الرئيسية والتعريف بالمنصة
│   ├── signup.html            # تسجيل حساب جديد (عميل / مونتير)
│   ├── login.html             # تسجيل الدخول
│   ├── dashboard_client.html  # لوحة العميل (رفع طلب جديد + تتبع التقدم)
│   ├── dashboard_editor.html  # لوحة المونتير (تنزيل الخام + تحديث الحالة)
│   └── dashboard_admin.html   # لوحة تحكم الأدمن والرقابة المركزية
├── backend/                   # خادم Flask وقاعدة البيانات
│   ├── app.py                 # نقطة الانطلاق الرئيسية للخادم
│   ├── config.py              # إعدادات السيرفر والأمان والمسارات
│   ├── models.py              # جداول قاعدة البيانات (SQLAlchemy)
│   ├── routes_auth.py         # مسارات المصادقة والتسجيل والجلسات
│   ├── routes_orders.py       # مسارات إدارة ورفع ومتابعة الطلبات
│   ├── routes_admin.py        # مسارات لوحة الإدارة ونظام الحظر والإنذارات
│   ├── add_admin.py           # سكريبت إضافة حساب الأدمن الأول
│   └── ai_agent.py            # عقل الذكاء الاصطناعي للردود والاستفسارات
├── bot/                       # بوت تيليجرام المساعد الشخصي للمونتير
│   └── bot_main.py            # معالجة الأوامر وتحديث الحالات فورياً
├── cpp_engine/                # محرك C++ فائق السرعة
│   ├── compress.cpp           # ضغط مجلدات الماتريال إلى ZIP
│   ├── video_info.cpp         # فحص بيانات وأحجام ملفات الفيديو
│   └── Makefile               # أوامر البناء والكومبايل
├── uploads/                   # مجلد تخزين الملفات والماتريال المرفوعة
└── requirements.txt           # مكتبات بايثون المطلوبة
```

## 🚀 طريقة التثبيت والتشغيل السريع (Quickstart)

### 1. تثبيت المتطلبات (Prerequisites)
تأكد من وجود Python 3 و C++ Compiler (g++):
```bash
pip install -r requirements.txt
```

### 2. بناء محرك C++
ادخل مجلد المحرك وقم ببنائه بضغطة واحدة:
```bash
cd cpp_engine
make
cd ..
```

### 3. إنشاء حساب الأدمن الأول
```bash
python backend/add_admin.py admin admin@chromaproduction.com admin123456
```

### 4. تشغيل خادم Flask
```bash
python backend/app.py
```
سيعمل الخادم افتراضياً على: `http://127.0.0.1:5000`

### 5. تشغيل بوت تيليجرام المساعد (اختياري / في نافذة منفصلة)
اضبط رمز التوكن الخاص ببوتك في البيئة ثم شغله:
```bash
export TELEGRAM_BOT_TOKEN="YOUR_BOT_TOKEN_HERE"
python bot/bot_main.py
```

## ⚙️ مميزات المنصة

1. **دورة عمل كاملة وشفافة:**
   - العميل يرفع الماتريال حتى 250 ميجا ويحدد نوع الخدمة (ريلز، يوتيوب، إعلانات).
   - المونتير ينزل الخام بضغطة زر.
   - المونتير يحدث الحالة إما من لوحة التحكم أو من تيليجرام برسمية أو بلغة طبيعية ("خلصت التقطيع"، "بلون دلوقتي").
   - العميل يرى مؤشر نسبة الإنجاز والوصف العربي للحالة فورياً.

2. **الأمان والرقابة الإدارية:**
   - نظام إنذارات تلقائي (3 إنذارات يتبعها حظر تلقائي للحساب).
   - مراقبة كافة الطلبات والتقييمات من لوحة الأدمن.
